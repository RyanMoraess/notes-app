# Notes App

Android notes app built with Kotlin and Jetpack Compose. Create, list, edit and delete notes, with local persistence using Room.

## Features
- Create notes (title, content, done/pending)
- List, edit and delete notes
- Data persisted locally on the device

## Tech stack
- Kotlin
- Jetpack Compose
- Room (SQLite)
- ViewModel

## Getting started
1. Clone this repository
2. Open it in Android Studio
3. Run the app on an emulator or device
